# VitaTwin - AI Fatigue Detection System

## Overview
VitaTwin is an AI-powered fatigue detection and digital twin system that analyzes user behavior using computer vision and machine learning.

## Features
- Eye tracking & gaze detection
- Head pose estimation
- Fatigue scoring system
- Cognitive + physical fatigue analysis
- LSTM-based prediction module
- Personalized user profiling

## Tech Stack
- Python
- OpenCV
- MediaPipe
- Machine Learning (LSTM)
- Computer Vision

- main.py
